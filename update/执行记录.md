### 2.1 对诊断结论的更正（纪律⑥：新增文件写更正 + 证据）

| # | 诊断原文 | 实测更正与证据 |
|---|---|---|
| **C1（更正）** | D4 把「`data/index/manifest.json`、`data/proposals/v1/*.json` 工作树比 index blob 大」写成既成漂移 | 方向正确，但**根因是本机 `core.autocrlf=true` 的单向改写**：`git ls-files --eol` → `i/lf w/crlf`。仓库 blob 一直是 LF；只有工作树被写成 CRLF。因此修法必须**同时**把已漂移的工作树归一，否则首次 `git add` 会把 CRLF 固化进历史 |
| **C2（更正）** | D5 只点了 `tools/gen_snapshots.py --check` 会"先写后比" | **`tools/gen_proposals.py --check` 有同款缺陷**（`generate_proposals()` 真写盘后再读回来比）。本批一并改成只读 |
| **C3（更正）** | 提示词 ①「不许改测试/跳测试/删断言」+ sdist 内 `pytest` 必须全绿 | sdist **没有 `.git`**，两条 git 类门（`check-attr` / `ls-files`）在源码包里无法执行。处理：显式 `skipif` + **反向锚** `test_git_attr_gates_are_active_in_repo`（断言仓库态必须有 `.git`），防止在仓库里被永久 skip 变成假门 |
