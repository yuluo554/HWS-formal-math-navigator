## 二、退出码语义

### 2.1 退出码定义

| 退出码 | 语义 | 说明 |
|--------|------|------|
| **0** | 成功 | 所有检查通过 |
| **1** | 未达标 | 检查未通过（如基准不达标） |
| **2** | 用法错误 | 参数错误、文件不存在等 |
| **3** | 依赖缺失 | 缺少必要依赖（如 Lean 工具链） |
| **4** | 配置错误 | 配置项错误或缺失 |

### 2.2 CLI 命令退出码

| 命令 | 成功 (0) | 未达标 (1) | 用法错误 (2) | 依赖缺失 (3) |
|------|----------|------------|--------------|--------------|
| `hws_formal_math search` | 找到结果 | 无结果 | 参数错误 | - |
| `hws_formal_math generate` | 骨架生成成功 | 生成失败 | 参数错误 | 模型未配置 |
| `hws_formal_math verify` | 验证通过 | 验证失败 | 参数错误 | Lean 未安装 |
| `hws_formal_math bench` | 基准达标 | 基准未达标 | 参数错误 | - |
| `hws_formal_math selftest` | 自检通过 | 自检失败 | - | - |

### 2.3 退出码测试

```python
# tests/test_cli_exit_codes.py

def test_search_success(capsys):
    """搜索成功退出码 0"""
    with pytest.raises(SystemExit) as exc_info:
        cli.main(["search", "加法结合律"])
    assert exc_info.value.code == 0

def test_search_no_results(capsys):
    """搜索无结果退出码 1"""
    with pytest.raises(SystemExit) as exc_info:
        cli.main(["search", "不存在的定理"])
    assert exc_info.value.code == 1

def test_verify_without_lean(capsys):
    """无 Lean 工具链退出码 3"""
    with mock.patch("shutil.which", return_value=None):
        with pytest.raises(SystemExit) as exc_info:
            cli.main(["verify", "#eval 1+1"])
        assert exc_info.value.code == 3
```

## 二之二、桌面查看器验收（v0.1.1 新增）

> 背景：v0.1.0 的查看器"按钮没有 `connect`、Release 里没有产物"，而测试全绿——

| 层 | 验什么 | 落点 |
|---|---|---|
| 控制器层 | 检索排序 / 空查询报错 / 构图分列 index_gap / 导出 0 外链 | `tests/test_viewer.py::TestViewerController`（6 条） |

**形态四格（delivery-forms §零）**：

| 形态 | 主入口 | 主控件/命令 | 接到哪个业务函数 | 断言在哪条测试 | 产物在哪个附件 |
|---|---|---|---|---|---|
| CLI | `hws-formal-math` | `search`/`bench`/`selftest` | `Orchestrator.*` | `test_cli.py` / `test_repo_gate.py` | 三平台 zip |

## 四、测试编写规范

### 4.1 单元测试规范

```python
# 示例：检索器测试

def test_retrieval_basic():
    """基本检索功能"""
    retriever = Retriever(INDEX_PATH)
    results = retriever.search("加法结合律")
    assert len(results) > 0
    assert all("score" in r for r in results)

def test_retrieval_deterministic():
    """同输入同结果"""
    retriever = Retriever(INDEX_PATH)
    results1 = retriever.search("加法结合律")
    results2 = retriever.search("加法结合律")
    assert results1 == results2

def test_retrieval_no_lean():
    """无 Lean 时检索可用"""
    retriever = Retriever(INDEX_PATH)
    results = retriever.search("加法结合律")
    # 不依赖 Lean，直接返回索引结果
    assert results is not None
```

## 五、测试运行命令

### 5.1 本地运行

```bash
# 运行全部测试
pytest tests/

# 运行指定测试文件
pytest tests/test_retriever.py

# 运行指定测试
pytest tests/test_retriever.py::test_retrieval_deterministic

# 带覆盖率
pytest tests/ --cov=src/hws_formal_math --cov-report=html

# 运行基准测试
python -m hws_formal_math bench

# 运行自检
python -m hws_formal_math selftest
```

### 5.2 CI 运行

**实况**（`.github/workflows/ci.yml`，M6 收尾期对齐）：四矩阵 `ubuntu-latest`/`windows-latest` × Python `3.8`/`3.12`。

```yaml
# .github/workflows/ci.yml（节选）
name: CI
on:
  push:
    branches: [main]
  pull_request:
    branches: [main]
  workflow_dispatch:
  release:
    types: [published]

jobs:
  test:
    runs-on: ${{ matrix.os }}
    strategy:
      fail-fast: false
      matrix:
        os: [ubuntu-latest, windows-latest]
        python-version: ["3.8", "3.12"]
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0        # 历史扫描类守门需要完整历史
      - uses: actions/setup-python@v5
        with:
          python-version: ${{ matrix.python-version }}
      - run: echo "PYTHONUTF8=1" >> $GITHUB_ENV   # 编码守卫：救 CI 全部步骤
      - run: pip install -e ".[dev]"
      - run: pytest tests/ -v --tb=short
      # 安装面第四面：裸 console-script 与 python -m 是两条通路
      - run: hws-formal-math selftest
      - run: python -m hws_formal_math selftest
      - run: hws-formal-math bench --suite retrieval
      - run: hws-formal-math bench --suite depgraph
```

**CI 首跑对账口径**：每个 push/tag 事件恰一 run，逐提交以 `head_sha`+`conclusion` 配对（见 `plan/RELEASE-M6.md`）。
