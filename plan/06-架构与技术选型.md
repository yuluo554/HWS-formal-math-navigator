## 一、架构总览

### 1.1 系统分层

```
┌─────────────────────────────────────────────────────────────┐
│                    展示层（CLI + 桌面查看器）                  │
│  cli/          — 命令行入口（主交互）                         │
│  viewer/       — 轻桌面查看器（PySide6，依赖图可视化）          │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│                    编排层（Orchestration）                    │
│  core/orchestrator.py  — 主流程编排（检索→骨架→验证→报告）    │
│  core/model_gateway.py — 模型接入网关（可插拔开关）            │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│                    引擎层（Engine Layer）                     │
│  engine/retriever.py    — 检索器（BM25，零模型）              │
│  engine/skeleton_gen.py — 骨架生成器（模型在环）              │
│  engine/kernel.py       — 内核验证器（Lean 4 调用）           │
│  engine/depgraph.py     — 依赖图构建器（确定性图算法）         │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│                    数据层（Data Layer）                       │
│  data/index/      — 数学库索引元数据（定理名/签名/依赖边）     │
│  data/snapshots/  — 预置模型输出快照                          │
│  data/proposals/  — 合成命题集（可/不可形式化对照）            │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│                    基础设施（Infrastructure）                  │
│  core/config.py      — 配置管理（模型端点、Lean 路径等）       │
│  core/logging.py     — 日志（UTF-8 守卫）                     │
│  core/exceptions.py  — 异常体系（退出码语义）                  │
│  tests/              — 测试套件                               │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 核心设计原则

| 原则 | 落点 | 验证方式 |
|------|------|----------|
| **确定性优先** | 检索/依赖图零模型依赖 | 无 Lean 工具链时降级可用 |
| **模型可插拔** | 模型开关默认关，不随包分发权重 | 设置页可配端点；关闭时全功能降级 |
| **内核硬真值** | Lean 4 编译结果 = 唯一真值 | 不合成真值台账；报告分列 sorry 状态 |
| **版本化快照** | mathlib4 挂 commit hash；索引元数据入仓 | sha256 留档；重建索引可复跑 |
| **报告分离** | 模型生成与内核判定在报告中分离呈现 | 报告模板显式分两节 |
| **边界显式** | 前置条件（Lean 用户自备）写进 README | 降级路径实测存在 |

## 二、技术选型

### 2.1 语言与运行时

| 组件 | 选型 | 理由 |
|------|------|------|
| **主语言** | Python 3.12+ | v0.1.2 起抬 floor（3.8 已 EOL，且与 setuptools>=77 的 PEP 639 SPDX license 不可兼得）；PyInstaller 打包成熟；Lean 4 有 Python API |
| **打包工具** | PyInstaller ≥6 | GUI（PySide6）必须 ≥6（5.x 确定性崩）；CLI 可 ≥5.13 |
| **测试框架** | pytest | 成熟、跨平台、支持参数化 |

### 2.2 依赖库

| 库 | 用途 | 版本约束 | 备注 |
|----|------|----------|------|
| **PySide6** | 桌面查看器 | ≥6.0 | GUI 依赖；CLI 不引（分档打包） |
| **numpy** | 向量计算（检索） | ≥1.20 | 可选；纯 Python 余弦可降级 |
| **scikit-learn** | BM25 实现 | ≥1.0 | 可选；纯 Python 实现可降级 |
| **PyYAML** | 配置解析 | ≥5.1 | 核心依赖 |
| ~~jinja2~~ | ~~报告模板渲染~~ | — | **v0.1.2 已移除**：全仓 0 处 import，报告实际由 `core/report.py` 的 f-string 生成（DEC5=A） |
| **python-lean4** | Lean 4 Python API | 最新 | 可选；用户自备 Lean 时可用 |

### 2.3 Lean 工具链集成

| 组件 | 状态 | 集成方式 |
|------|------|----------|
| **elan** | 用户自备 | 命令行调用 `lean --version` 检测 |
| **Lean 4** | 用户自备 | 子进程调用 `lean --check` 验证片段 |
| **mathlib4** | 版本化快照 | 用户自取源码；工具只入索引元数据 |

### 2.4 模型接入

| 端点类型 | 配置方式 | 默认状态 |
|----------|----------|----------|
| **OpenAI 兼容端点** | `config.yaml` 中 `model.endpoint` | 关闭 |
| **llama.cpp server** | `config.yaml` 中 `model.llama_cpp_path` | 关闭 |
| **omni-infer（昇腾）** | `config.yaml` 中 `model.omni_infer_url` | 关闭 |

## 四、分层与单向依赖

### 4.1 依赖规则

```
展示层 → 编排层 → 引擎层 → 数据层
    ↑
基础设施（横切）
```

| 层 | 可依赖 | 不可依赖 |
|----|--------|----------|
| 展示层 | 编排层、基础设施 | 引擎层、数据层 |
| 编排层 | 引擎层、基础设施 | 展示层、数据层（直接） |
| 引擎层 | 数据层、基础设施 | 展示层、编排层 |
| 数据层 | 基础设施 | 所有上层 |
| 基础设施 | 标准库 | 所有层 |

### 4.2 模块隔离

| 模块 | 隔离方式 | 原因 |
|------|----------|------|
| **viewer/** | 独立入口；CLI 不引 | GUI 依赖 PySide6；CLI 打包分档 |
| **engine/kernel.py** | try/except ImportError | Lean 4 可选；用户自备 |
| **core/model_gateway.py** | try/except ImportError | 模型端点可选；默认关闭 |

## 七、本机环境坑（实测）

| 坑 | 现象 | 处置 |
|----|------|------|
| Python 版本 | 本机 3.12（3.8 已于 2024-10 EOL） | v0.1.2 起 floor = 3.12；构建用 3.12（PyInstaller ≥6） |
| PyInstaller 5.x 崩 | GUI 构建 `Instruction object is not iterable` | GUI 必须 PyInstaller ≥6 |
| 中文控制台编码 | `py -X utf8` 习惯 | 入口 `_ensure_utf8_stdio()`；测试用 cp1252 复现 |
| Git Bash 路径 | `/tmp` 与 Windows Python 路径不通 | 临时文件用工作区相对路径 |
| pip 注册表代理污染 | `https://127.0.0.1:7897` 错误 | `NO_PROXY="*" py -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple` |
