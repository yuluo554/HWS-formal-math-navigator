## 二、决策记录表

| 日期 | 决策 | 结论与理由 |
|---|---|---|
| 2026-10-15 | **命名约定：目录标签改用 `HWS-`** | 用户明确要求。本批三题统一 `HWS-` 前缀，GitHub 仓库名用纯净名。**用户表态优先于系列旧惯例** |
| 2026-10-15 | **本批为"以 openPangu-2.0-Flash 为引擎"的题，引入新纪律「模型在环，但审计核心零模型可跑」** | **92B MoE 本地自举硬件门槛高（Q4 约 50GB 权重）**，任何"免安装 exe 内自带模型"的承诺都会踩**交付物可达性预检**。故：模型接入 = 可插拔显式开关，**不随包分发权重**；检索与依赖图核心 = 纯确定性、零模型依赖、可离线复跑；基准 = 预置快照 + 内核硬真值 |
| 2026-10-15 | **本题关键边界：Lean/elan 工具链 = 用户自备前置条件，绝不承诺 exe 内自举** | mathlib4 全量编译**数 GB 磁盘、小时级**——若承诺"免安装 exe 内自举 Lean 工具链"，M5 必然踩"交付物可达性预检"。故：题面与 README 显式声明前置条件；工具只对**声明片段/预编译缓存**验证，**不对全库重编译**；未装工具链时检索与依赖图**降级可用**（该降级路径必须真实存在） |
| 2026-10-15 | **mathlib4 以版本化快照接入，随仓只存索引元数据** | 完整源码数 GB，不适合入仓；且版本漂移会让检索结果不可复现。故：挂 **commit hash** 固定版本，随仓只存**定理名/签名/依赖边**等索引元数据 + sha256 留档；用户可自取源码重建索引 |
| 2026-10-15 | **本题真值 = Lean 内核编译结果（系列中最强可核验真值）** | 通过/失败**无歧义**，不需要合成真值台账、不需要"评分标准"。这是本题相对另两题的核心优势 |
| 2026-10-15 | **`sorry` 占位不计入"证明成功"** | 含 `sorry` 的骨架"编译通过"但**未证明**——若不区分，会把"空洞证明"报成"证明成功"（判定虚高）。报告须分列"通过且无 sorry"与"通过但含 sorry" |
| 2026-10-15 | **模型生成与内核判定在报告中分离呈现** | 防"模型说对了"被读成"内核验证通过"。内核判定是硬真值，模型输出是候选——混述会造成虚假可信 |
| 2026-10-15 | **`index_gap` 与"定理不存在"必须区分** | 索引未覆盖某模块 ≠ 该定理不存在。误判会让用户以为命题无解。索引覆盖度必须显式登记 |
| 2026-10-15 | **弃"形式化忠实度自动保证"** | 自然语言命题 → Lean statement 是否**语义等价**，无法靠工具自动保证（本质上是难题）。列边界：忠实度须人工确认，工具只做语法校验与内核验证 |
| 2026-10-15 | **弃"证明自动补全全部 sorry"** | 全自动补全在 2026 年仍是开放难题；承诺即为不可达承诺。本工具产出**骨架 + 占位 + 候选定理**，列扩展项为"部分 sorry 的 Agent 尝试填充" |
| 2026-10-15 | **弃"数学 OCR / Lean 之外的证明助手适配"入首期** | OCR 属 CV 域；跨助手适配工程量大且非该模型特长。均列扩展项 |
| 2026-10-15 | **弃"论文格式/文献审计 / AIGC 检测"** | 与系列⑪文献审计工作台撞域 |
| 2026-10-15 | **如实登记：本题工程量为三题中最重** | 需处理 Lean 工具链、mathlib4 索引、内核调用、Agent 循环；Windows 上 Lean 部署摩擦大。**风险写进题面**，不粉饰 |

### 弃选项汇总（skill 要求必写）

| 弃选项 | 弃因 |
|---|---|
| 形式化忠实度自动保证 | 本质难题，工具无法自动保证；列为边界（人工确认） |
| 全自动补全全部 sorry | 2026 年仍开放；承诺即不可达；列扩展项 |
| 数学 OCR / 跨证明助手适配 | 属 CV 域 / 工程量过大，非首期 |
| 论文格式/文献审计 / AIGC 检测 | 与系列⑪文献审计工作台撞域 |
| 纯 mathlib 文档检索网站 | 非确定性工具，且已有邻近件（lean-graph 等）；无内核判定闭环 |
| LLM 数学答疑 | 非确定性工具，LLM 聊天可直接替代 |

## 五、本批新纪律备忘（跨三题共用）

1. **模型在环，但审计核心零模型可跑**——模型接入为可插拔显式开关、不随包分发权重、基准用预置快照+真值台账。
2. **发布类里程碑 DoD 三件套**——tag · Release（附产物）· 发布留档，缺一即未达成。
3. **真值覆盖度门槛**——按题型/定理域列最低覆盖项，分母反射自代码常量，堵死"悄悄做小分母"。
4. **本题特有**：前置条件边界（Lean 用户自备）必须写进题面与 README，且**降级路径真实存在、措辞与实现逐字一致**。
