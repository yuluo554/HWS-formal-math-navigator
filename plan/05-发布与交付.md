## 前置条件

### 必需

### 可选（功能分级）

| 功能 | 前置条件 | 说明 |

### Lean 工具链安装指引

```bash
# 1. 安装 elan（Lean 版本管理器）
curl --proto '=https' --tlsv1.2 -sSf https://sh.leanprover.com | sh

# 2. 安装 Lean 4
elan default leanprover/lean4:stable

# 3. 验证安装
lean --version

# 4. 下载 mathlib4（可选，用于完整检索）
git clone https://github.com/leanprover-community/mathlib4.git
cd mathlib4
lake update
```

### 模型端点配置

```yaml
# config.yaml
model:
  enabled: false  # 默认关闭
  endpoint: https://api.openai.com/v1  # OpenAI 兼容端点
  api_key: ${OPENAI_API_KEY}
  model: openpangu-2.0-flash
  # 或使用 llama.cpp server
  # llama_cpp_path: /path/to/llama.cpp/server
  # omni_infer_url: http://localhost:8080
```

### 免责声明

> **本工具不随包分发 Lean 工具链、模型权重或 mathlib4 完整源码。**
> - Lean / elan 工具链 = 用户自备前置条件
> - 模型接入 = 可插拔显式开关，默认关闭
> - mathlib4 以版本化快照接入，随仓只存索引元数据
> - 未装 Lean 工具链时：检索与依赖图降级可用，内核验证标注"未执行"
```

### 3.2 前置条件检测

```python
# core/requirements.py

def check_lean_available() -> bool:
    """检查 Lean 工具链是否可用"""
    return shutil.which("lean") is not None

def check_model_configured(config: Config) -> bool:
    """检查模型端点是否配置"""
    if not config.model.enabled:
        return False
    if config.model.endpoint:
        return bool(config.model.api_key)
    if config.model.llama_cpp_path:
        return os.path.exists(config.model.llama_cpp_path)
    return False

def get_requirements_report() -> dict:
    """生成前置条件报告"""
    return {
        "lean": {
            "available": check_lean_available(),
            "required_for": ["内核验证"],
            "degradation": "检索与依赖图可用"
        },
        "model": {
            "configured": check_model_configured(load_config()),
            "required_for": ["骨架生成"],
            "degradation": "接受已形式化输入"
        }
    }

### 4.3 构建脚本

```python
# tools/package.py

import subprocess
import shutil
from pathlib import Path

def build_cli():
    """构建 CLI exe"""
    subprocess.run([
        "pyinstaller",
        "--name", "hws-formal-math",
        "--console",
        "--hidden-import", "hws_formal_math.cli",
        "src/hws_formal_math/cli.py"
    ], check=True)

def build_gui():
    """构建 GUI exe"""
    subprocess.run([
        "pyinstaller",
        "--name", "hws-formal-math-viewer",
        "--windowed",
        "--hidden-import", "hws_formal_math.viewer.main",
        "--collect-all", "PySide6",
        "src/hws_formal_math/viewer/main.py"
    ], check=True)

def build_distribution():
    """构建全部产物"""
    # 清理
    shutil.rmtree("dist", ignore_errors=True)
    
    # CLI
    build_cli()
    
    # GUI
    build_gui()
    
    # 源码包
    subprocess.run(["python", "-m", "build", "--sdist"], check=True)
    
    # wheel
    subprocess.run(["python", "-m", "build", "--wheel"], check=True)

def compute_sha256(file_path: Path) -> str:
    """计算 sha256"""
    import hashlib
    with open(file_path, "rb") as f:
        return hashlib.sha256(f.read()).hexdigest()

def generate_manifest():
    """生成产物清单"""
    manifest = []
    for file_path in Path("dist").iterdir():
        if file_path.is_file():
            manifest.append({
                "file": file_path.name,
                "size": file_path.stat().st_size,
                "sha256": compute_sha256(file_path)
            })
    return manifest
```

## 五、CI 配置

### 5.1 GitHub Actions 工作流

```yaml
# .github/workflows/ci.yml
name: CI
on: [push, pull_request, workflow_dispatch]

jobs:
  test:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        python-version: [3.8, 3.12]
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: ${{ matrix.python-version }}
      - run: pip install -e ".[dev]"
      - run: pytest tests/ --cov=src/hws_formal_math

  build:
    runs-on: ubuntu-latest
    needs: test
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"
      - run: pip install -e ".[all]"
      - run: pip install pyinstaller
      - run: python tools/package.py
      - uses: actions/upload-artifact@v4
        with:
          name: dist
          path: dist/

  release:
    runs-on: ubuntu-latest
    needs: [test, build]
    if: startsWith(github.ref, 'refs/tags/')
    steps:
      - uses: actions/download-artifact@v4
        with:
          name: dist
          path: dist/
      - uses: softprops/action-gh-release@v1
        with:
          files: dist/*
```
